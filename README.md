## 项目基线

- 目标平台：Windows 10
- 形态：绿色便携桌面应用
- 默认目录：D:\WorkManager
- 业务数据：本地保存，不上传云端
- 技术方向：Tauri 2、Svelte 5、TypeScript、Rust、SQLite + SQLCipher

# T1-03 证据脱敏说明（P2-01 修复）

**背景：** 第一轮独立审计发现 T1-03 证据目录包含原始命令日志，日志中出现 Windows 计算机名、
账户名、用户目录和本地绝对路径，违反 AGENTS.md 第 7 节“不提交构建产物、真实数据库、密钥、日志、
用户附件或机器专属路径”的仓库交付规范。

**修复时间：** 2026-11-19（第二轮定向修复）
**修复范围：** `docs/testing/reports/T1-03-assets/`

## 1. 执行的处理

1. **删除原始命令日志。** `logs/` 目录（9 个原始命令输出文件，含 PowerShell/Release 运行日志）
   整目录从仓库删除；原始日志不再进入仓库，本机副本仅保存在仓库外（gitignored）用于复核。
2. **保留机器可读证据并脱敏。** 保留全部 10 个 JSON 证据、17 张验收截图、`test-counts.txt`
   与本说明；对 JSON/文本中的机器标识与路径做等价替换。
3. **不删除测试结果。** 断言数量、PASS/FAIL、错误码、UUID、时间戳、SHA-256、计数等
   可复核信息全部保留；脱敏脚本只做字符串替换（见第 3 节）。
4. **历史清理。** 上述文件只存在于 T1-03 的 docs/evidence 提交中；已重写该任务分支的该类提交并
   使用 `--force-with-lease` 推送，具体旧/新 HEAD 与恢复引用记录在
   [`../T1-03-REPORT.md`](../T1-03-REPORT.md) 的“第二轮定向修复”章节。

## 2. 脱敏占位符

| 原始内容类型 | 占位符 |
|---|---|
| Windows 计算机名 | `<computer-name>` |
| Windows 账户名 / 用户标识 | `<user>` / `<redacted>` |
| 用户目录（`C:\Users\<user>`） | `<user-profile>` |
| 仓库检出绝对路径 | `<repo-root>` |
| UAT 测试根路径（`D:\WorkManager-test-data`） | `<uat-root>` |
| Windows 系统目录（`C:\WINDOWS`） | `<windows-root>` |
| Python 可执行文件绝对路径 | `<python-exe>` |

说明：产品默认部署路径 `D:\WorkManager` 是 PRD/DEC-002 明确定义的产品路径，不是本机专属路径，
在文档中保留；UAT 证据中实际运行的测试根目录统一替换为 `<uat-root>`。

## 6. 复核方法

- 机器标识模式在扫描时由运行环境变量（计算机名、账户名、用户目录）与仓库根路径**动态生成**，不硬编码进仓库。
- 分支增量历史：逐提交扫描树中全部文本文件；当前证据目录：UTF-8/系统编码双解码 + PNG 文本块解析；PR 文本：GitHub API 只读拉取后内存扫描。
- 旧提交原始日志：仅按类别统计匹配数量，原文不落盘、不输出。
- 复现命令与测试数量见 `test-counts.txt` 与 [`../T1-03-REPORT.md`](../T1-03-REPORT.md)。

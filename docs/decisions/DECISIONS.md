## 变更规则

1. 已确认决策不得由实现者或 AI 助手自行改变。
2. 需要改变已确认决策时，先记录变更原因、影响范围和迁移/兼容方案，再取得用户确认。
3. 助手建议、技术推测和开源项目默认行为不得写成用户已确认决策。
4. 需求、架构和代码出现冲突时，先暂停相关实现，核对本文件及 PRD。
5. 已确认决策中的合并门禁（DEC-033）由用户控制，任何 AI Agent 不得自行绕过或合并 PR。
6. 用户最新明确决策优先于任何旧文档、AI 建议和技术默认值；新决策必须记录到本文件并同步相关文档。
